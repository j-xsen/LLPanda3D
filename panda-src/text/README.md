# Text — Panda3D's C++ Text Rendering System

**Source:** `panda/src/text/` · Library: `libp3text` · Notify category: `text`

This module turns a Unicode string plus a `TextFont` into renderable Panda3D
geometry. It has three layers:

1. **Fonts** — `TextFont` is the abstract interface; `StaticTextFont` wraps a
   pre-rendered egg-mkfont model, `DynamicTextFont` rasterizes glyphs on the
   fly from a FreeType-readable font file (TTF, etc.), caching each glyph's
   bitmap into a `DynamicTextPage` texture atlas. `FontPool` unifies font
   loading by filename, the same way `TexturePool`/`ModelPool` do for their
   resource types.
2. **Properties** — `TextProperties` is a bag of visual/layout settings (font,
   color, alignment, wordwrap, shadow, scale, ...), each individually
   "specified or not" so nested property changes can layer additively.
   `TextPropertiesManager` is a global registry mapping names to
   `TextProperties`/`TextGraphic` structures, referenced from inside a string
   via embedded control characters.
3. **Assembly** — `TextNode` is the user-facing entry point (a `PandaNode`
   that is also a `TextEncoder` and a `TextProperties`); it lazily hands the
   actual layout work to `TextAssembler`, which parses embedded property
   references, wordwraps, and emits a tree of `Geom`s (or merges them into
   batched quads).

## Core concepts

**Text strings carry embedded control characters, not markup tags.** A
`TextNode`'s string (as seen by `TextAssembler::scan_wtext()`) can contain
single Unicode code points, configurable via `Config.prc`, that act as
structural tokens:

| Default | Config variable | Meaning |
|---|---|---|
| `\x01` | `text-push-properties-key` | Push a named `TextProperties` (name follows, terminated by another `\x01`) — e.g. `"x\x01up\x01n\x02 + y"` renders `n` in the `"up"` properties |
| `\x02` | `text-pop-properties-key` | Pop back to the previous properties |
| `\x03` | `text-soft-hyphen-key` | Optional hyphenation point; invisible unless a line actually breaks there |
| `\x04` | `text-soft-break-key` | Optional line-break point that leaves no visible character |
| `\x05` | `text-embed-graphic-key` | Embed a named `TextGraphic` (name follows, terminated by another `\x05`) |

`TextPropertiesManager::get_global_ptr()` is where the names referenced by
`\x01`/`\x05` are looked up. Nested pushes compose additively via
`TextProperties::add_properties()` — a pushed structure only overrides the
fields it has explicitly set, layered on top of whatever was already active
(see [TextProperties.md](TextProperties.md)).

**`TextNode` rebuilds lazily, on a dirty flag, guarded by a mutex.** Setter
calls (`set_text_color()`, `set_wordwrap()`, ...) just flip dirty bits and
return immediately; the actual `TextAssembler` run is deferred to the next
cull pass or an explicit `update()`/`force_update()`. See
[TextNode.md](TextNode.md) for the flag mechanics, including the
`do_measure() == do_rebuild()` quirk (no cheap remeasure-only path exists).

**Two different glyph representations: quads and arbitrary Geoms.** A glyph
that boils down to one textured rectangle (`TextGlyph::has_quad()`) can be
batched extremely cheaply — `TextAssembler` collects all same-`RenderState`
quads into one shared `GeomVertexData`/`GeomTriangles` pair
(`generate_quads()`). A glyph with real geometry (wireframe/polygon/extruded
render modes, or a hand-built `StaticTextFont` glyph without a detected quad)
instead goes through `GeomCollector`, which manually copies rows into a merged
`GeomVertexData`, deduplicating vertices per source primitive. Both paths are
controlled by `TextNode::set_flatten_flags(FF_dynamic_merge)` /
`TextAssembler::set_dynamic_merge()`; when merging is off, each glyph gets its
own individual `Geom` instead (`GlyphPlacement::assign_to()`), relying on the
scene graph flattener to combine them later.

**`GeomTextGlyph` exists purely so glyph reference counts can be tracked
through `Geom` copies.** Every `Geom` a `TextGlyph` hands out
(`TextGlyph::get_geom()`) is actually a `GeomTextGlyph` wrapping it, carrying
a list of the `TextGlyph`s that contributed vertices. `DynamicTextFont::garbage_collect()`
and `DynamicTextPage::garbage_collect()` use `TextGlyph::get_ref_count() == 1`
(i.e. only the font's own cache holds a reference) to decide a glyph is no
longer rendered anywhere and can be evicted/erased from its texture page.
Without `GeomTextGlyph` tracking references across `copy_primitives_from()`/
batching, that ref-count would go to 1 the moment the original per-glyph
`Geom` was merged away.

**Cheesy accents and ligatures are synthesized, not always real glyphs.**
`TextAssembler::get_character_glyphs()` consults `UnicodeLatinMap` (a
separate `panda/src/putil` table, not part of this module) to find an ASCII
base-letter glyph plus an `AccentType` when the font lacks a precomposed
accented glyph. `tack_on_accent()` then looks up a plain combining-accent-mark
glyph and positions/transforms/scales it relative to the base glyph's tight
bounding box — a purely cosmetic approximation, not real font hinting.

**HarfBuzz shaping is optional and per-run.** If Panda was built with
`HAVE_HARFBUZZ` and `text-use-harfbuzz` is true, `TextAssembler::assemble_row()`
batches consecutive same-properties characters (only for `DynamicTextFont`s)
into an `hb_buffer_t` and calls `shape_buffer()`, which uses HarfBuzz's own
glyph-index-based advance/offset output instead of Panda's naive
character-by-character advance + kerning path. Without HarfBuzz (or for
`StaticTextFont`), text always uses the simpler per-character path with
optional `text-kerning`.

**The default font is compiled directly into the library.** When no font is
set and `text-default-font` isn't configured, `TextProperties::load_default_font()`
falls back to a font byte array baked into `libp3text` at build time
(`COMPILE_IN_DEFAULT_FONT`): "Perspective Sans" (`persans.ttf`) via
`DynamicTextFont` if `HAVE_FREETYPE`, otherwise a pre-baked `.bam` model
("Computer Modern Sans Serif", `cmss12`) loaded as a `StaticTextFont` via
`BamFile` (optionally zlib-decompressed).

## Config variables (`config_text.cxx`)

Grouped roughly by what they affect; see the `PRC_DESC` string in
`config_text.cxx` for exact wording.

| Variable | Default | Affects |
|---|---|---|
| `text-flatten` | `true` | `TextNode::set_flatten_flags()` default (`FF_strong` if true) |
| `text-dynamic-merge` | `true` | `FF_dynamic_merge` default — see quad/GeomCollector batching above |
| `text-kerning` | `false` | Enable font kerning tables (ignored when HarfBuzz shaping is active) |
| `text-use-harfbuzz` | `false` | Enable HarfBuzz shaping (see above) |
| `text-anisotropic-degree` | `1` | Default anisotropic filtering for `DynamicTextFont` page textures |
| `text-texture-margin` | `2` | Texels of padding reserved around each glyph in a `DynamicTextPage` |
| `text-poly-margin` | `0.0` | Extra geometric margin added to each glyph's quad |
| `text-page-size` | `256 256` | Default `DynamicTextPage` texture size |
| `text-small-caps` | `false` | `TextNode`/`TextProperties` default `small_caps` |
| `text-small-caps-scale` | `0.8` | Scale applied to synthesized small-caps letters |
| `text-default-font` | `""` | Filename to load as the fallback font (else the compiled-in one) |
| `text-tab-width` | `5.0` | Default tab stop width |
| `text-push-properties-key` / `text-pop-properties-key` | `1` / `2` | Control chars, see table above |
| `text-soft-hyphen-key` / `text-soft-break-key` | `3` / `4` | Control chars, see table above |
| `text-embed-graphic-key` | `5` | Control char, see table above |
| `text-soft-hyphen-output` | `"-"` | String substituted when a line actually breaks at a soft hyphen |
| `text-hyphen-ratio` | `0.7` | If the last breakable space falls before this fraction of the line, hyphenate instead |
| `text-never-break-before` | `",.-:?!;"` | Characters that should never start a line after a forced break |
| `text-max-never-break` | `3` | Cap on how many trailing never-break characters get pulled back |
| `text-default-underscore-height` | `-0.2` | Default `TextProperties::get_underscore_height()` |
| `text-minfilter` / `text-magfilter` / `text-wrap-mode` / `text-quality-level` | linear / linear / border_color / best | `DynamicTextPage` texture sampler defaults |
| `text-render-mode` | `RM_texture` | Default `TextFont::RenderMode` for `DynamicTextFont` |
